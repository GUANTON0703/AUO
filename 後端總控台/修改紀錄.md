## 2026-08-19 10:10 — 修正 UNC 路徑導致 pip 崩潰問題

### 問題
pip 在 UNC 路徑（`\\server\...`）執行時，import 自身模組失敗
錯誤點：`pip\__main__.py` → `from pip._internal.cli.main import main`

### 根本原因
Python 跑在 UNC 路徑時，`sys.path` 內的 UNC entry 會讓 import 機制崩潰
這是 Python on Windows UNC path 的已知問題

### 解法
BAT 使用 `pushd` 將 UNC 路徑對應為磁碟機代號（如 Z:\），
再用磁碟機路徑執行 Python，pip import 就正常運作
mapped base 路徑以 argv[1] 傳入 setup_packages.py

### 修改檔案
- `202608191006.bat` → `202608191010.bat`（加入 pushd/popd 機制）
- `setup_packages.py` → 同名覆蓋 v3（接收 BASE 參數，TARGET_DIR 用 mapped path）

## 六、獨立 BAT 啟動器範本（工具自帶）

```bat
@echo off
setlocal

set "PYTHON=\\tw100049089\00_MyAgent\Python\Python312\python.exe"
set "APP_PATH=\\tw100049089\00_MyAgent\<工具資料夾>\app.py"
set "URL=http://localhost:5101"

echo Starting <工具名>...
start /B "" "%PYTHON%" "%APP_PATH%"

echo Waiting for server ready...

:CHECK_READY
timeout /t 1 /nobreak >nul
powershell -NoProfile -Command ^
  "try{$r=(iwr '%URL%' -UseBasicParsing -TimeoutSec 2 -EA Stop).StatusCode;if($r-eq 200){exit 0}else{exit 1}}catch{exit 1}" >nul 2>&1
if errorlevel 1 goto CHECK_READY

echo Server is ready!
start "" "%URL%"

endlocal
```

> ⚠️ 最後一行必須是 `start "" "http://localhost:PORT"`，不可直接開 HTML 檔案路徑
